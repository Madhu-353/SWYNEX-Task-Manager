# SWYNEX Task Manager

## Project Overview

SWYNEX Task Manager is a planned full-stack web application designed to help users create, organize, update, and track their daily tasks.

Users will be able to register, log in, create tasks, update tasks, mark tasks as completed, and delete tasks.

## Project Goals

- Create a simple and user-friendly task management application.
- Allow users to securely manage their own tasks.
- Connect a frontend application with a backend REST API.
- Store application data in a database.
- Understand and demonstrate full-stack application architecture.

## Planned Features

- User registration
- User login
- User logout
- Create tasks
- View tasks
- Update tasks
- Delete tasks
- Mark tasks as completed
- Set task priority
- Set due dates
- Filter tasks
